01 / What’s new

Familiar mail.
More capable terminals.

Skadi keeps Alpine’s keyboard-driven workflow, mail configuration, and Pico composer. These are the additions in the fork.

01Images in your mail
See image attachments and embedded HTML images directly in the message viewer. Thumbnails preserve their proportions, adapt to terminal resizing, and work over SSH with the kitty graphics protocol.
02A richer composer
Add bold, italic, headings, links, lists, quotes, and inline images with keyboard shortcuts. Send HTML with a plain-text alternative, preview that text before sending, and resume HTML drafts. Optional formatted replies preserve basic markup.
03Files across the connection
Use the kitty file-transfer protocol to download attachments to the computer running your terminal, or attach files from that computer to a remote mail session. Choose one attachment or download them together.
04Modern keyboard input
Support for the kitty keyboard protocol and modified keys makes Alt shortcuts available throughout the composer. Bracketed paste keeps pasted text from turning into editor commands.
05Browser sign-in, less copying
OAuth authorization can receive a browser callback locally, with a clickable sign-in link and a responsive authorization screen. Remote sessions provide instructions for forwarding the callback over SSH.
06Mail when the link drops
Read previously cached IMAP mail offline. Keep flag changes and deletions for the next sync, and queue failed sends in a local outbox. A cache-first option lets you open cached folders before contacting the server.

02 / The terminal is part of the experience

At home in
kitty & Silkie.

Skadi uses the graphics, keyboard, and file-transfer protocols provided by kitty and inherited by Silkie, Goblin Reactor’s fork of kitty.

Image rendering also supports iTerm2 images and sixel. Available features depend on the terminal and connection.

A few practical details

  • File transfers require a direct terminal session; the current transfer path does not run through tmux or screen.
  • Kitty and iTerm2 images under tmux need passthrough enabled.
  • On macOS, configure Option to send Alt for the composer’s formatting shortcuts.
  • The offline cache and new relay workflow target Unix systems.

03 / Meet Njord

Your connection home.

Njord is Skadi’s companion IMAP proxy. Run it on your home Linux computer and let that machine talk to your mail provider.

Available now: a forwarding shell. Njord relays traffic in both directions, with verified TLS to the upstream server and optional TLS for clients. It does not yet compress mail or implement the new IMAP extension.

The next step is an IMAP extension designed for low-bandwidth, high-latency connections. Njord will translate it back to conventional IMAP, keeping the back-and-forth with your provider on the home side of the satellite link.

The goal is practical mail afloat or off the grid, using a proxy you run yourself. The extension, compression, and satellite performance are future work; the current release establishes the relay.

04 / Get started

Take it for a run.

Skadi and Njord live in the same repository. Skadi builds on Alpine’s C codebase; Njord uses Python’s standard library.

macOS · Homebrew

Native Apple Silicon bottle, built and tested on macOS 26 Tahoe.

brew tap goblinreactor/tap https://brew.goblinreactor.com/homebrew-tap.git
brew install goblinreactor/tap/skadi goblinreactor/tap/njord
skadi

Linux · APT

Ubuntu 26.04: AMD64 and ARM64. Kylin V10 SP1: old-world LoongArch64.

Add the Goblin Reactor APT repository for your distribution, then:

sudo apt update
sudo apt install skadi njord

Skadi 0.1.0 · Njord 0.1.1. Native builds from localhost, naamah, graviton5, and loongson. Packages retain Alpine’s configuration paths and upstream version banner. Njord installs separately; no relay service starts automatically.

Build Skadi from source

Use Alpine’s build prerequisites for your platform.

git clone https://github.com/adamdeprince/skadi.git
cd skadi
./configure
make
./alpine/alpine

The source build currently retains the alpine executable name and existing Alpine configuration paths.

Install the Njord relay

Requires Python 3.8 or newer. No Python packages to download.

make -C njord install PREFIX="$HOME/.local"
$HOME/.local/bin/njord \
  --upstream imap.example.com

Replace the example with your provider’s IMAP hostname. Njord listens on 127.0.0.1:1143 and connects upstream with verified TLS on port 993. Use listener TLS or an encrypted tunnel for remote access.
